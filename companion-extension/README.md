# StudyOS Learning Companion

A minimal Chromium browser companion for StudyOS.

## What it can access

- The currently active tab after you click the extension.
- Text you deliberately select on that page.
- The current page title and URL.

It does **not** request browser history permission.

## Local installation

1. Open your Chromium browser's extensions page.
2. Enable developer mode.
3. Choose **Load unpacked**.
4. Select this `companion-extension` folder.
5. Open a lesson page and click the StudyOS Companion icon, or select text and use **Capture selection to StudyOS**.

The extension opens the StudyOS `/capture` review screen. Nothing is saved until the signed-in student confirms the capture.
